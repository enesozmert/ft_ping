# Report — Proje Raporu Klasörü

Bu klasör, ft_ping projesinin teslim raporu ve durum dokümanlarını
içerir.

| Dosya                            | Kapsam                                                |
|----------------------------------|-------------------------------------------------------|
| [report.md](report.md)           | Ana proje raporu (subject uyumluluk + mimari + test)  |

## Diğer Klasörlerle İlişki

- **`docs/rules/`** — projenin uyduğu kural setleri.
- **`docs/tasks/`** — proje görev listesi (`Task.md`).
- **`docs/command/`** — build & run komutları (Linux/macOS/Windows/Docker/CMake).
- **`docs/presentation/`** — defense / sunum slaytları.
- **`docs/normcheck/`** — Norminette denetim raporu.
- **`docs/cppcheck/`** — Cppcheck + MISRA denetim raporu.
- **`docs/main/`** — orijinal subject PDF.
